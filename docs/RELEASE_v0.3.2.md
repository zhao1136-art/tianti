# 御天分析 v0.3.2 发布报告（压缩包健壮性修复）

- 发布日期：2026-10-31
- 类型：缺陷修复（行为兼容）
- 交付：`dist\御天分析-0.3.2-便携版.zip`

## 修复内容

1. **损坏/改名/截断的 .zip 不再只报「压缩包解析失败」**
   - 之前：扩展名为 zip 但内容不是有效 ZIP 时，仍按「压缩包展开」路径处理，显示「已静态分析 0/0 个条目（已截断）」，
     只有一条 archive.malformed 信号，容易被误认为程序异常/崩溃。
   - 现在：识别为 malformed，expanded=false，结果备注明确写：
     「压缩包解析失败：BadZipFile: File is not a zip file。该文件扩展名/类型为 zip，但内容不是有效 ZIP
     （可能损坏、被截断、加密或改名）；已回退为原始数据静态分析（字符串 / 熵 / 内嵌载荷），不展开条目。」
   - 同时回退做字符串、IoC、整体熵、内嵌 PE/ZIP/宏/脚本标记检查（之前压缩包路径会跳过这些）。

2. **解压异常兜底**
   - ZipFile 打开 / 读取目录 / 单条目解压的异常全部捕获，转成 extra.archive.malformed/error 与可读备注；
   - 单条目损坏只跳过该条目，不影响其他条目与整体判定。

3. **CLI / GUI 提示**
   - CLI：压缩包: 解析失败（...），已按原始数据静态分析；
   - GUI 摘要/压缩包 tab：显示解析失败原因与回退说明。

## 验证

- 新增 4 个回归用例：垃圾 zip、截断 zip、空 zip、以及「假 zip 里内嵌 PE 仍触发 data.embedded_pe」；
- 全量测试：400 tests OK（1 skipped）；
- 打包版实测：bad.zip 扫描不再显示「0/0 已截断」，改为明确解析失败 + 回退说明；
- 产物 SHA256 见 dist\SHA256SUMS.txt。

## 说明

- 有效 zip 的逐条目静态分析行为不变（100 条 / 64MB / 32MB 限制）；
- 损坏压缩包不会被展开，因此不会执行/解析其中未知内容；结论基于原始字节静态信号。
